# 网事1999 · NetEra-1999

> 你穿越回了 1999。拨号上网的电流声里，中文互联网刚刚睁开眼。
> 一款回合制经营策略游戏——用文明 6 的骨架，重走中国互联网 1999–2010 黄金十年。

## 它是什么

从 1999 Q1 到 2010 Q4，共 48 个回合（1 回合 = 1 季度）。你在中关村的民房里注册公司，
研发技术、上线产品、烧钱推广、拉投资、雇大佬当顾问，与真实历史擦肩而过——
直到 2010 年终，用估值和腾讯、百度、阿里同台排名，评定 S–E 级称号。

**破产即败，活下来靠的是现金流、时代红利，和一点点穿越者的先知。**

## 核心系统

| 系统 | 说明 |
|---|---|
| 科技树 | 16 项技术分四时代：BBS → 门户 → SP/网游/IM → 搜索/SNS/电商 → 手机客户端/开放平台/移动支付 |
| 产品经营 | 立项开发、定价策略（免费/标准/高价）、运营热度、版本迭代、产品老化、停运止损 |
| 历史事件 | 30+ 真实事件按时间轴触发：OICQ 诞生、纳斯达克崩盘、传奇燎原、非典、百度上市、iPhone、3Q 大战…… |
| 行业冲击波 | 重大事件会真实冲击你的财报：非典线上需求井喷 ×1.25、金融海啸 ×0.8，持续数季 |
| 先驱者系统 | 你在历史节点前做出同类产品（比如 2005 前上线移动支付），事件文案改写、抢走用户、声望大涨 |
| 风云人物 | 马云、马化腾、丁磊、李彦宏、陈天桥、周鸿祎、雷军、王兴、熊晓鸽……好感度 + 顾问增益 |
| 风险投资 | 可投阿里/腾讯/百度/网易/卓越/美团/小米种子轮，历史年份兑现回报（S 级通关密码） |
| 上市系统 | 满足条件可 IPO 敲钟，募资 25% 流通——此后承担合规成本、股价波动、财报压力等「上市阵痛」 |
| 政策卡 | 双槽位公司战略：烧钱推广、免费战略、资本运作、快速跟随…… |
| 难度 | 休闲 / 标准 / 硬核三档 + 六种出身 + 五选一穿越物资 |

## 技术栈

- **React 18 + TypeScript + Vite**
- **Tailwind CSS 4**（Win98 复古视觉：斜面窗体、渐变蓝标题栏、CRT 扫描线）
- **WebAudio** 实时合成全部音效（拨号音、收银机、成就琶音……零素材文件）
- 零后端，localStorage 自动存档；主题 UI 随四个时代自动演化

## 快速开始

```bash
npm install
npm run dev      # 本地开发
npm run build    # 生产构建 → dist/
```

建议桌面端 + Chrome 体验。

## 项目结构

```
src/
├── App.tsx                # 状态编排：reducer 接线、存档、音效触发、主题切换
├── game/
│   ├── types.ts           # 全部类型定义
│   ├── data.ts            # 数值表：科技/产品/政策/人物/事件/难度/时代主题
│   ├── engine.ts          # 回合结算、事件解析、估值、融资、IPO、成就
│   └── sfx.ts             # WebAudio 复古音效引擎
├── components/
│   ├── panels.tsx         # 主界面九大面板 + 事件弹窗 + 成就墙
│   ├── screens.tsx        # 开机/注册/结局三个全屏页面
│   └── ui.tsx             # Win98 窗体、按钮、图标、迷你走势图
└── index.css              # Win98 chrome + CRT 扫描线 + 动效
```
