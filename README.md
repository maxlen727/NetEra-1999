# 1999：中文互联网创业模拟器

> 穿越回 1999 年，在中国互联网的黄金时代创业！

## 🎮 游戏简介

你是一名穿越者，回到了 1999 年——中文互联网刚刚兴起的年代。从中关村的一间小办公室开始，你将经历中国互联网从门户时代到移动互联网时代的完整历程。

**玩法类似《文明 6》**：每回合是一个季度（48 回合 = 1999 年 Q1 至 2010 年 Q4），你需要做出研发、产品、市场、融资等战略决策，与历史人物互动，在时代的浪潮中生存并壮大。

## 🎯 游戏机制

### 四个时代
| 时代 | 时间 | 主题 |
|------|------|------|
| 门户时代 | 1999–2001 | 三大门户叱咤风云 |
| SP 与网游时代 | 2001–2004 | 短信淘金，传奇燎原 |
| Web 2.0 时代 | 2004–2007 | 百度上市，全民博客 |
| 移动互联网时代 | 2007–2010 | iPhone 来了，3G 来了 |

### 三种难度
- **休闲模式**：启动资金×1.5，工资−20%，收入 +15%，适合看剧情
- **标准模式**：原汁原味的 1999 年体感
- **硬核模式**：启动资金×0.75，工资 +25%，收入−15%，地狱开局

### 核心资源
- 💵 **资金**：发工资、搞研发、买服务器
- 👥 **团队**：决定开发速度和行动力（AP）
- 📈 **用户**：产品的生命线（单位：万）
- ⭐ **声望**：品牌影响力，影响估值和融资
- 🔬 **技术**：研发进度解锁新产品

## 📁 项目结构

```
src/
├── game/
│   ├── data.ts      # 游戏数据：事件、人物、产品、科技树
│   ├── engine.ts    # 游戏引擎：回合逻辑、数值计算
│   ├── types.ts     # TypeScript 类型定义
│   └── sfx.ts       # 音效处理
├── components/
│   ├── screens.tsx  # 主界面：开始菜单、结算画面
│   ├── panels.tsx   # 功能面板：研发、产品、财务
│   └── ui.tsx       # UI 组件库
├── App.tsx          # 应用入口
└── main.tsx         # React 渲染入口
```

- .com 泡沫与纳斯达克崩盘

- 百度上市创造造富神话
